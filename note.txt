## 1. Chuẩn bị dữ liệu annotation

Dữ liệu ban đầu gồm ảnh và file annotation Pascal VOC XML:

```text
dataset_pest_detect/
├── images/
│   ├── Ampelophaga/
│   ├── army worm/
│   ├── beet army worm/
│   ├── cabbage army worm/
│   └── Cabbage_test/
└── annotations/
    ├── Ampelophaga/
    ├── army worm/
    ├── beet army worm/
    ├── cabbage army worm/
    └── Cabbage_test/
```

Mỗi ảnh có một file XML tương ứng chứa thông tin class và bounding box của sâu.

Ví dụ annotation Pascal VOC:

```xml
<object>
    <name>Ampelophaga</name>
    <bndbox>
        <xmin>112</xmin>
        <ymin>43</ymin>
        <xmax>137</xmax>
        <ymax>176</ymax>
    </bndbox>
</object>
```

Ý nghĩa:

```text
name: tên loại sâu
xmin, ymin: tọa độ góc trên bên trái của bounding box
xmax, ymax: tọa độ góc dưới bên phải của bounding box
```

## 2. Chuyển dữ liệu Pascal VOC sang định dạng train

Trước khi train, hệ thống chuyển dữ liệu XML sang định dạng TXT đơn giản để mô hình dễ đọc hơn.

Chạy file:

```powershell
python prepare_voc_dataset.py
```

Sau khi chạy, chương trình tạo ra thư mục mới:

```text
dataset_pest_bbox/
├── images/
│   ├── train/
│   ├── val/
│   └── test/
├── annotations/
│   ├── train/
│   ├── val/
│   └── test/
└── classes.txt
```

File annotation sau khi chuyển có dạng:

```text
class_id xmin ymin xmax ymax
```

Ví dụ:

```text
0 112 43 137 176
```

Trong đó:

```text
0 = Ampelophaga
1 = army worm
2 = beet army worm
3 = cabbage army worm
```

File `classes.txt` chứa danh sách class:

```text
Ampelophaga
army worm
beet army worm
cabbage army worm
```

## 3. Train mô hình phát hiện sâu bằng MobileNetV2 và Bounding Box Regression

Sau khi chuẩn bị dữ liệu, hệ thống train mô hình phát hiện sâu bằng file:

```powershell
python train_bbox_detector.py
```

Mô hình sử dụng MobileNetV2 làm backbone để trích xuất đặc trưng ảnh. Sau đó, mô hình có hai nhánh đầu ra:

```text
class_output: dự đoán loại sâu
box_output: dự đoán vị trí bounding box
```

Kiến trúc tổng quát:

```text
Ảnh đầu vào
→ MobileNetV2 Backbone
→ Global Average Pooling
→ Dropout
→ Nhánh phân loại class
→ Nhánh dự đoán bounding box
```

Trong đó:

```text
class_output = [p1, p2, p3, p4]
box_output = [x_min, y_min, x_max, y_max]
```

Các giá trị bounding box được chuẩn hóa trong khoảng từ 0 đến 1. Khi hiển thị lên ảnh gốc, hệ thống nhân các giá trị này với chiều rộng và chiều cao thật của ảnh.

Kết quả sau khi train được lưu tại:

```text
runs/pest_bbox_mobilenet/
├── best_model.keras
├── final_model.keras
└── classes.txt
```

Trong đó:

```text
best_model.keras: mô hình tốt nhất theo val_loss
final_model.keras: mô hình cuối cùng sau khi train
classes.txt: danh sách class
```

## 4. Hàm loss trong quá trình train

Do mô hình có hai đầu ra nên sử dụng hai hàm loss khác nhau.

Nhánh phân loại sử dụng:

```text
Categorical Crossentropy
```

Nhánh bounding box sử dụng:

```text
Mean Squared Error
```

Tổng loss của mô hình:

```text
Loss_total = Loss_class + α * Loss_box
```

Trong chương trình, hệ số `α` được đặt lớn hơn 1 để tăng mức độ ưu tiên cho việc học vị trí bounding box.

Ví dụ:

```text
Loss_total = 1.0 * Loss_class + 5.0 * Loss_box
```

## 6. Tinh chỉnh vùng sâu bằng GrabCut và Contour

Do mô hình MobileNetV2 + Dense chỉ dự đoán một bounding box từ toàn ảnh nên box có thể bị lệch hoặc quá to. Để kết quả hiển thị tốt hơn, hệ thống sử dụng thêm thuật toán GrabCut của OpenCV.

Quy trình tinh chỉnh:

```text
Bounding box thô từ mô hình
→ Dùng box làm vùng khởi tạo cho GrabCut
→ Tách foreground và background
→ Tạo mask vùng vật thể
→ Xử lý morphology để giảm nhiễu
→ Tìm contour lớn nhất
→ Vẽ contour và box tinh chỉnh
```

GrabCut giúp tách vùng sâu khỏi nền ảnh tốt hơn, đặc biệt trong trường hợp sâu có hình dạng dài hoặc cong. Sau đó, contour lớn nhất được chọn làm vùng nghi là sâu.

## 9. So sánh với phương pháp chia patch

Ban đầu có thể dùng cách chia ảnh thành nhiều patch nhỏ rồi đưa từng patch qua mô hình phân loại pest/non_pest. Cách này có ý tưởng:

```text
Đọc ảnh
→ Chia ảnh thành nhiều ô nhỏ
→ Đưa từng ô qua model phân loại
→ Nếu xác suất pest vượt ngưỡng thì vẽ khung
→ Gộp các vùng phát hiện
```

Tuy nhiên, trong phiên bản hiện tại, hệ thống không sử dụng `patch_inference.py` nữa. Thay vào đó, hệ thống sử dụng mô hình học trực tiếp bounding box từ annotation. Cách này phù hợp hơn vì mô hình được học trực tiếp vị trí sâu thay vì phải quét từng vùng nhỏ.

So sánh:

```text
Patch inference:
- Không cần annotation bounding box
- Chạy chậm do phải quét nhiều patch
- Box thường không chính xác
- Phù hợp chạy thử khi chỉ có model phân loại

Bounding box regression:
- Cần annotation bounding box
- Dự đoán vị trí trực tiếp
- Chạy nhanh hơn chia patch
- Phù hợp hơn với bài toán phát hiện vị trí sâu
```

## 11. Ghi chú về hạn chế

Mô hình hiện tại không sử dụng YOLO mà sử dụng MobileNetV2 kết hợp hồi quy bounding box. Vì vậy, mô hình đơn giản hơn nhưng có một số hạn chế:

```text
Chỉ dự đoán tốt khi ảnh có một con sâu chính
Box có thể lệch hoặc to nếu dữ liệu ít
Không phù hợp tốt với ảnh có nhiều sâu cùng lúc
Độ chính xác phụ thuộc nhiều vào chất lượng annotation
GrabCut chỉ là bước hậu xử lý, không thay thế được mô hình detection chuyên dụng
```

Tuy nhiên, phương pháp này vẫn phù hợp với mục tiêu xây dựng một hệ thống phát hiện sâu đơn giản, dễ triển khai, không sử dụng YOLO, có khả năng dự đoán loại sâu và vị trí sâu trên ảnh.
